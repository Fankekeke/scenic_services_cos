# 基于 SpringBoot + Vue 的 智能景区系统 (Smart Scenic Area System)

智慧旅游平台 · 景区与酒店一体化管理 · AI 导览 · 在线预约 · 数据可视化.

本项目是一套面向智慧旅游场景的综合性景区管理平台，采用前后端分离架构，覆盖“景区游览、酒店预订、用户互动、运营管理、数据分析”等核心业务。平台支持管理员、酒店、用户三类角色协同工作，提供景区与酒店订单管理、在线支付、二维码核销、AI 景区介绍、景区导航、天气预报、社区论坛、评价投诉以及多维度数据看板等功能，适用于景区、文旅平台、智慧旅游城市及多景区运营场景。

## 核心特性

- **景区与酒店一体化运营**：统一管理景区门票、酒店预订、用户订单与评价，形成完整旅游服务闭环。
- **AI 智能导览**：提供 AI 景区介绍、景点推荐、景区导航与实时天气信息，提升游客出行体验。
- **二维码订单核销**：支持景区订单二维码生成与核销，简化入园流程，提高现场管理效率。
- **多维度数据看板**：提供月度统计、年度分析、销售预测、热力分布、流量排行、标签词云等可视化分析能力。
- **社区互动与服务沟通**：内置景点论坛、公告信息、评价系统与酒店在线沟通，增强用户参与感。
- **智能推荐与人流监测**：支持用户景区推荐、热门景点排行及景区人流浏览检测，辅助运营调度。

## 功能模块概览

### 管理员端

管理员端负责平台整体运营、景区与酒店管理、订单核销及数据分析：

**平台基础管理**

- **公告管理**：发布景区通知、活动信息、运营公告与维护提醒。
- **用户管理**：管理注册用户资料、账户状态及平台使用权限。
- **论坛管理**：管理景点论坛帖子、评论及违规内容，维护社区秩序。
- **消息回复**：处理用户消息、反馈与平台通知交互。

**景区与酒店管理**

- **景点管理**：维护景区基本信息、介绍、门票规则、开放时间及标签。
- **酒店管理**：审核并维护入驻酒店信息、服务内容与运营状态。
- **房间信息**：查看各酒店房间类型、价格、库存与可用状态。
- **景区评价 / 酒店评价**：监管用户对景区和酒店的评分与文字反馈。

**订单与核销管理**

- **景区订单**：查看全平台景区门票订单状态、支付情况与核销记录。
- **酒店订单**：管理酒店预订订单，跟踪入住状态与退款情况。
- **订单二维码核销**：生成景区订单二维码，支持现场扫码核销入园。

**数据统计与智能分析**

- **月度统计 / 年度分析**：按月、按年汇总订单量、收入、用户增长等核心指标。
- **销售预测**：基于历史订单数据预测未来景区与酒店销售趋势。
- **热力分布**：展示景区、酒店及热门区域的热力图分布。
- **流量排行**：统计热门景区、热门酒店、热门帖子访问与订单排行。
- **评分与消费分析**：分析用户评分分布、客单价及消费偏好。
- **区域景区数量分析**：按地区统计景区数量、酒店数量及订单分布。
- **评级与数量分析**：分析景区/酒店评级结构与数量变化。
- **价格与消费分析**：统计门票价格、酒店房价与用户消费区间。
- **景区标签词云分析**：基于景区标签、评价关键词生成词云，辅助内容运营。

### 酒店端

酒店端面向入驻酒店，提供订单处理、房间管理与用户沟通功能：

**酒店基础管理**

- **酒店信息**：维护酒店名称、地址、联系方式、设施介绍与服务规则。
- **房间管理**：添加、编辑、上下架房间，设置房型、价格、库存与入住规则。

**订单与评价管理**

- **我的订单**：查看酒店预订订单，处理确认入住、取消、退款等状态。
- **入住评价**：查看用户对酒店及房间的评分与评价，优化服务质量。
- **酒店订单图表统计**：可视化展示酒店订单量、入住率、收入趋势等数据。

**用户服务**

- **用户沟通**：在线回复用户咨询，处理预订问题、入住需求与售后反馈。

### 用户端

用户端以小程序或 H5 为主要入口，提供景区浏览、预订、导览与社区互动体验：

**景区浏览与智能服务**

- **用户景区推荐**：根据热门程度、评分或用户偏好推荐景区与行程。
- **现在出发**：快速查看附近或推荐景区，支持立即规划行程。
- **AI 景区介绍**：通过 AI 生成景区讲解、游玩建议与亮点推荐。
- **景区导航**：提供景区位置展示、路线规划与导航服务。
- **景区天气预报**：查看景区实时天气与未来天气趋势，辅助出行安排。
- **景区人浏览检测**：展示景区当前热度、浏览量或人流趋势，帮助用户错峰出行。

**订单与支付**

- **景区订单**：查看景区门票订单状态、费用明细与核销二维码。
- **酒店订单**：查看酒店预订订单、入住信息及订单状态。
- **订单支付宝在线支付**：支持通过支付宝完成景区门票与酒店订单支付。

**互动与个人中心**

- **个人中心**：管理个人资料、联系方式、订单记录与账户信息。
- **我的贴子**：查看自己发布的论坛帖子、评论与互动内容。
- **景点论坛**：浏览景点相关帖子，参与讨论、分享游玩经验。
- **公告信息**：查看平台公告、景区通知与活动信息。
- **景区评价 / 酒店评价**：对已游览景区或已入住酒店进行评分与文字评价。
- **酒店在线沟通**：与酒店方在线沟通，咨询房型、入住时间与服务细节。
